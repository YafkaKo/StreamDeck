# Локальный сервер CS2 для турнира

Сервер работает только в локальной сети арены (`sv_lan 1`), серверы Valve для самой игры не нужны.
Каждому игроку всё равно нужен запущенный Steam с CS2.

## Что где

| Файл | Зачем |
|---|---|
| `settings.bat` | IP сервера (`SERVER_IP`, по умолчанию `auto` — определяется сам), папка установки (`C:\CS2Server`), стартовая карта, порты, число слотов |
| `install.bat` | Ставит SteamCMD и сервер CS2 (~75 ГБ). Повторный запуск обновляет сервер — делайте это после каждого обновления CS2, иначе игроки не подключатся |
| `firewall.bat` | Открывает порты 27015 (UDP/TCP), 27020 (UDP) и 8080 (панель). Запускать от имени администратора, один раз |
| `start-server.bat` | Копирует конфиги из `cfg\` в сервер и запускает его. Показывает адрес для игроков |
| `install-plugins.bat` | Ставит/обновляет моды турнирного режима: Metamod + CounterStrikeSharp + MatchZy (нож-раунд, `!ready`, `!pause`) |
| `start-server-noplugins.bat` | Запасной запуск без модов, если после обновления CS2 сервер с ними не стартует |
| **`panel.bat`** | **Панель админа в браузере: кнопки для карты, старта матча, паузы, кика, ботов.** Нужен Node.js |
| `rcon.bat` | Пульт админа: команды серверу с любого ПК арены (rcon из консоли игры в CS2 работает ненадёжно) |
| `cfg\server.cfg` | Название сервера, **пароль**, rcon, GOTV |
| `cfg\gamemode_competitive_server.cfg` | Правила матча по образцу FACEIT: MR12, заморозка 20 с, овертаймы MR3 ($10 000), тайм-ауты, разминка. Урон по своим только от гранат (HE и огонь), пули по своим — 0 |
| `cfg\MatchZy\live.cfg` | Правила, которые MatchZy включает на старте матча (копия из плагина с нашей правкой урона по своим). При обновлении MatchZy сверить с новой версией плагина |

## Перенос на другой компьютер

1. Скачайте эту папку на новый ПК (`git clone` или ZIP с GitHub) в любое место.
2. IP нового ПК определится сам (`SERVER_IP=auto` в `settings.bat`). Если определился не тот — впишите вручную.
   Лучше закрепить IP за ПК на роутере, чтобы он не сменился в день турнира.
3. Дальше — раздел «Подготовка» ниже. Чтобы не качать 75 ГБ заново, можно скопировать папку `C:\CS2Server` со старого ПК
   на новый по тому же пути и пропустить `install.bat` (понадобится только для обновлений; SteamCMD он скачает сам).
4. Игрокам сообщите адрес, который покажет `start-server.bat` (вместо `192.168.0.100` из примеров ниже).

Файлы `.bat` сохранены в кодировке CP866 (OEM). Редактируйте их Блокнотом/Notepad++ в этой кодировке, не пересохраняйте в UTF-8 — сломаются.

## Подготовка (один раз, лучше накануне)

1. Запустите `install.bat` и дождитесь «Готово» (скачивание ~75 ГБ).
2. Правой кнопкой по `firewall.bat` → «Запуск от имени администратора».
3. Откройте `cfg\server.cfg` и поменяйте `sv_password`, `tv_password` и `rcon_password`.
4. Запустите `start-server.bat` и с другого компьютера арены проверьте подключение.

Сервер лучше ставить на отдельный ПК, не на компьютер одного из игроков.

## Турнирный режим (MatchZy, как на FACEIT)

После `install.bat` один раз запустите `install-plugins.bat` (сервер должен быть закрыт). Дальше `start-server.bat` сам запускает сервер с модами.

**Ход матча:** разминка → все игроки пишут в чат `!ready` → нож-раунд → победители пишут `!stay` или `!switch` → матч (MR12, овертаймы MR3 с $10 000).

| Игроки пишут в чат | Что делает |
|---|---|
| `!ready` / `!unready` | Готов / не готов. Матч стартует, когда готовы все подключённые |
| `!stay` / `!switch` | После нож-раунда: остаться на стороне / поменять |
| `!pause` / `!unpause` | Пауза в начале следующего раунда. Снять паузу должны обе команды |
| `!tech` | Техническая пауза |

Админ управляет из панели (кнопки сами переключаются на команды MatchZy): «Начать матч» стартует без ожидания `!ready`,
«Нож-раунд вкл/выкл», «Откатить раунд…» (восстановить начало нужного раунда после сбоя), пауза и сброс в разминку.

**После обновления CS2** моды могут перестать работать (сервер не стартует или падает). Тогда: `install-plugins.bat`
(скачает свежие версии; авторы обычно выпускают их за несколько часов – пару дней), а если свежих ещё нет — `start-server-noplugins.bat`
(без нож-раунда и `!ready`, матч стартует кнопкой «Начать матч»). **Перед турниром CS2 и сервер не обновляйте.**

## Панель админа (кнопки в браузере)

1. Один раз установите Node.js (LTS) с https://nodejs.org.
2. Запустите сервер (`start-server.bat`), затем `panel.bat` — откроется браузер с панелью.
3. Пароль для входа — `rcon_password` из `cfg\server.cfg`.
4. С другого ПК или телефона в сети арены: `http://<адрес сервера>:8080` (адрес показывает `start-server.bat`).

В панели: текущая карта и игроки (обновляется каждые 3 с), выбор карты, «Начать матч», пауза, рестарт, смена сторон,
кик игрока кнопкой, боты для проверки и поле для любой команды. Окно `panel.bat` не закрывайте, пока панель нужна.

## День турнира

1. `start-server.bat`. В чёрном окне скрипта будет адрес сервера и готовая команда `connect` для игроков.
2. Откроется окно `CS2 Server` — не закрывайте его (только сворачивайте), вместе с ним закроется сервер.
   Команды админа вводятся прямо в это окно или через `rcon.bat` (с любого ПК арены).
   Из консоли самой игры серверные команды не работают.
3. Все 10 игроков заходят, выбирают команды. Сервер ждёт в разминке без ограничения по времени.
4. Когда все готовы, в консоли сервера: `mp_warmup_end` — матч пошёл.

### Команды админа (в окне сервера или в rcon.bat)

| Команда | Что делает |
|---|---|
| `mp_warmup_end` | Начать матч |
| `mp_pause_match` / `mp_unpause_match` | Пауза (начнётся с заморозкой следующего раунда) / снять паузу |
| `changelevel de_inferno` | Сменить карту (правила матча сохраняются) |
| `mp_restartgame 1` | Перезапустить матч на текущей карте |
| `mp_swapteams` | Поменять команды сторонами |
| `status` | Кто подключён |
| `bot_quota 9` / `bot_kick` | Боты для теста: ровно 9 ботов / убрать всех (при смене карты пропадают). `bot_add_t` не используйте — в CS2 он добавляет по два бота |
| `kick <ник>` | Выкинуть игрока |

Демо каждой карты пишутся автоматически в `C:\CS2Server\game\csgo\replays` — пригодятся при спорах.
Лог консоли сервера: `C:\CS2Server\game\csgo\console.log`.

## Подключение игроков (10 человек)

1. Запустить CS2, в настройках включить консоль разработчика (Игра → «Включить консоль разработчика»).
2. Открыть консоль клавишей `~` (Ё) и ввести (IP и пароль — свои):

   ```
   password arena2026; connect 192.168.0.100:27015
   ```

3. Выбрать свою команду (T или CT).

## Подключение комментатора

**Вариант 1 — наблюдатель на сервере (без задержки, рекомендуется):**

```
password arena2026; connect 192.168.0.100:27015
```

При выборе команды нажать «Наблюдатель». Видно всех игроков, переключение между ними — мышью.

**Вариант 2 — через GOTV (для ПК трансляции/OBS):**

```
password arena2026; connect 192.168.0.100:27020
```

GOTV идёт с задержкой 105 секунд (стандарт CS2, игроки не смогут подсматривать по трансляции).
Не ставьте `tv_delay 0`: с ним игроков выкидывало при входе (`NETWORK_DISCONNECT_OVERFLOW`).
Для живого комментария без задержки используйте вариант 1.

## Если не подключается

- Сервер и все ПК должны быть в одной сети (`192.168.0.x`). Отключите VPN на сервере и у игроков.
- Ошибка версии — CS2 обновился: закройте сервер и запустите `install.bat` ещё раз.
- Не видно сервер — проверьте, что `firewall.bat` запускался от администратора.
